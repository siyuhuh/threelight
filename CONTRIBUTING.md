# Contributing

Use Node.js 24, run `npm ci`, and start the playground with `npm run dev`.

Before opening a pull request:

- Run `npm run build`.
- Check all presets, sliders, toggles, quality modes, orbit, zoom, and reset.
- Check a narrow viewport and keyboard access to the controls.
- For rendering changes, attach before/after images and include browser, GPU, viewport size, and quality mode.
- Keep added code and assets license-compatible, and document their source. Do not copy code or assets from the inspiration repository without explicit licensing permission.

When reporting a bug, include reproduction steps and any browser console errors. Frame-rate claims should include hardware and render settings.
